# Changelog

All notable changes to Image Stacker are documented here.

## 1.0.0 — 2026-10-10

First release.

- Paste and vertically combine clipboard images while retaining source resolution.
- Automatically refresh the clipboard after stack changes.
- Rename, label, reorder, delete, undo, clear, and save combined images.
- Add adjustable previews, PNG size reporting, and optional output fitting.
- Provide an Arch/Omarchy-friendly per-user installer and desktop launcher.
